Local Forecasting Lab · v2

Regression, a real neural net, and forecasting — running in your browser.

Edit the data table (or paste your own as CSV), pick a model, and run a forecast. Every computation — the regression fit, the neural network's training loop, the metrics, the chart — happens in plain JavaScript on this page via Assets/regression-engine.js. Nothing is sent anywhere, and it works with no internet connection once the page is loaded. Use "Compare All Models" to see every model's fit on the same data side by side. Classification (logistic regression, k-NN) is a natural next addition.
