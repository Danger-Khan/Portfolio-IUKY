What got built

Grouped by area — not a complete history, but everything substantial.

Resume, CV & Cover Letter Builder

Portfoilos/AI & ML/Assets/Resume,CV & Cover Letter

  • Six live document formats from one form — Resume, CV, Cover Letter, ATS Resume, Europass, and a Japanese rirekisho (履歴書) — with a format picker and per-format printing. Builder.js, Index.html
  • Draft autosave to localStorage, JSON import/export, and a Python CLI mirror (Printer.py) that formats the identical data outside the browser.
  • template.txt + Extractor.py — fill in a plain text file by hand, parse it into the same draft format, no browser required.
  • Seven example drafts (Industrial Engineering, Mechanical CAD, Programming, AI/ML, Embedded Systems, 3D & Graphics, GIS) — Imaad's real background, reframed per field.

AI/ML Labs

Portfoilos/AI & ML

  • Forecast Models pipeline — extractor.py → worker.py → printer.py, a genuine three-stage Python port of the browser's regression engine, backed by a real SQLite database.
  • Humanizer — a rule-based (not ML) AI-phrasing rewriter, later extended with five tunable options: intensity, length (shorten/extend), US/UK/AUS spelling, jargon removal, and fluency cleanup — mirrored identically in JS and Python.
  • Forecasting, Image, and NLP labs each moved to their own standalone page, with compact preview cards left on the main AI/ML page linking to them.

Slicer Lab

Portfoilos/CADCAMCAE/Assets/CAM/Slicer

  • A G-code analyzer that reads a picked .gcode file's real PrusaSlicer summary stats client-side via the File API — tested against the five actual print files already in this portfolio's CAM/Freelance folder.
  • A material settings advisor (real FDM temperature/fan/speed ranges) and a filament cost calculator, plus analyzer.py as a tested CLI companion.

Gamer Portfolio

Portfoilos/Gamer

  • Rewrote the copy to be upfront that Imaad is a fan of these games, not their developer — the portfolio exists to connect with fellow players.
  • Hover/tap-to-enlarge game cards revealing extra screenshots, UID, and the official site link.
  • Found and fixed two UIDs that were sitting correctly in their source .txt files but never made it into the page.

Root Page & Site-Wide

index.html, Assets/

  • Responsive pass (heading scale, footer wrapping, overflow fixes) and a real Credentials Archive section — 17 certifications pulled from the CV, wired to the carousel controls that were previously non-functional.
  • Self-hosted Tailwind CSS, Font Awesome, and Google Fonts for the root page, the CV, the FYDP video page, and the Creative & 3D portfolio — all four previously depended on external CDNs, which broke the site's own 100%-offline requirement.
  • Reactivated a fully-built but disabled "Core Performance" section (CGPA, Six Sigma, ISO 9001), fixed a hotlinked CV photo, and closed a real unclosed-<div> bug found along the way.

Validation & Testing

Validation & Testing/

  • index_test.ps1 — checks every page for title, meta description, viewport tag, heading structure, alt text, and duplicate IDs.
  • qc_report.ps1 — runs the validators together and reports findings with a Critical/Major/Minor severity split and an accept/reject disposition, run before nearly every commit referenced above.
What this page isn't claiming: Claude Code didn't design any CAD part, didn't invent any certification or job history, didn't decide what this site should say about Imaad — all of that is his, sourced from his real CV and real files. What it did do is turn direction into working code, quickly, across Python, JavaScript, HTML/CSS, and PowerShell, while holding to the constraints Imaad set along the way (100% offline, no mockups, real data or none at all).
