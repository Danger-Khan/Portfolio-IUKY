Local Forecasting Lab · v2

Regression, a real neural net, and forecasting — running in your browser.

Edit a data table (or paste your own as CSV), pick a model, and run a forecast. Every computation — the regression fit, the neural network's training loop, the metrics, the chart — happens in plain JavaScript, in Assets/Forecast Models/regression-engine.js. Nothing is sent anywhere, and it works with no internet connection once the page is loaded.

  • → Linear, weighted, and polynomial (degree 2/3) regression
  • → A real backprop-trained neural network (1 → N tanh → 1)
  • → "Compare All Models" side by side on your own data or CSV
  • → R², RMSE, MAE, a forward forecast, and a train/test self-test — all on this one page

Local Image Processing Lab

Brightness, contrast, blur, and color extraction — on your own image.

Upload any image — it never leaves this tab, there's no upload and no server. Adjust brightness, contrast and blur live, then pull out its dominant colors with a from-scratch k-means clustering pass over the pixel data, in Assets/Image Models/image-engine.js.

  • → Live brightness / contrast / blur, a real-time RGB histogram, and k-means color extraction
  • → A from-scratch pixel-filter & convolution editor — grayscale, Sobel edges, sharpen, crop, and more
  • → A tiny coordinate MLP trained live by hand-written backprop, right on this page
  • → A self-test that checks the color extraction against known ground truth

Local NLP Lab

Sentiment, keywords, and text stats — on whatever you type.

Lexicon-based sentiment scoring, term-frequency keyword extraction, and basic text statistics — all built from scratch in Assets/NLP Models/nlp-engine.js, no external library, no pretrained model download.

  • → Lexicon-based sentiment scoring, keyword extraction, and text stats
  • → Humanizer — rewrites stock AI-sounding phrasing, right on this page
  • → Slicer runs behind the Humanizer — grammatical word-class + tense tagging, no UI of its own
  • → A bitmap OCR extractor and a sentiment self-test, both on this page too

Resume, CV & Cover Letter Builder

One form, ten live previews, and a distraction-free full-screen editor.

Fill in a form once and watch a resume, a CV, a cover letter, an ATS-friendly plain resume, a Europass CV, a Japanese rirekisho, and now Spanish, French, Russian and German previews update live, side by side, in Assets/Resume,CV & Cover Letter/Builder.js. A full-screen mode gives the editor and preview the whole screen while you type, print any format straight to PDF, and a companion Python CLI formats the same exported JSON outside the browser.

  • → 10 live document previews: Resume, CV, Cover Letter, ATS, Europass, Japanese, Spanish, French, Russian, German
  • → Full-screen edit + preview mode, so you can see exactly how it will look while you type
  • → Autosaved draft, print-to-PDF, and JSON export/import
  • → A Python CLI (Printer.py) that formats the identical draft outside the browser
