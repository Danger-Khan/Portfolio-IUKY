Humanizer

Rewrites stock AI-sounding phrasing — "in today's fast-paced world," "it is important to note that," "utilize," "seamless" — into plainer, contracted language. Rule-based, not a trained model: every swap it makes comes from database.sql, right in this folder, so there's nothing hidden. Runs entirely in your browser.

Prefer the terminal? echo "your text" | python backend.py from this folder runs the identical rule set through backend_pipeline.py and SQLite instead of the browser — useful for batch-processing files.
What this actually is: a fixed set of phrase, word, and contraction substitutions — the same ones listed in database.sql. It's not a language model and it doesn't understand meaning — it just recognizes specific stock phrasing and swaps it. Good for catching the obvious tells, not a substitute for actually rewriting in your own voice.
