Resume, CV & Cover Letter Builder

A real, working document builder — not a mockup. Fill in the form once to get six live previews side by side: a resume, a longer CV, a matching cover letter, an ATS-friendly plain resume, a Europass CV, and a Japanese rirekisho (履歴書) — print any of it straight to PDF, or export the draft as JSON and hand it to Printer.py, a command-line companion in this same folder that formats the identical data outside the browser.

Draft saves automatically to this browser — nothing is sent anywhere.

Prefer the terminal? Export the draft above, then run python Printer.py your_draft.json --type all from this folder to get all six formats as plain text — add --type ats, europass, or japanese for just one.

Or skip the form entirely: fill in template.txt by hand (any text editor), then run python Extractor.py template.txt --print — it produces the same draft.json this page exports, which you can also load back in with "Import Draft" above.
