Companion pipeline

The same regression math, as a real Python pipeline.

The Forecasting Lab on the main AI/ML page runs entirely in your browser via regression-engine.js. This folder holds a second, independent implementation of the same three models — ordinary least squares, weighted least squares, and polynomial regression — as a genuine three-stage Python pipeline backed by a real SQLite database, runnable from a terminal with no browser at all.

Back to the Forecasting Lab

Extract → Fit → Report

Three small scripts, each doing one job, chained by a shared SQLite database.

1 · extractor.py

Extract

Loads database.sql into SQLite on first run (auto-seeded with the lab's own 10-point sample dataset), then pulls a dataset out as clean (x, y, weight) tuples.

View extractor.py →
2 · worker.py

Fit

The actual regression math — Gaussian elimination for polynomial fits, weighted least squares, R²/RMSE/MAE — a line-for-line Python port of regression-engine.js. Stores the fit, forecast, and metrics back to the database.

View worker.py →
3 · printer.py

Report

Reads a stored run back out and formats it as a readable report — equation, fit quality, and the forecasted points — to the terminal or a text file.

View printer.py →
$ python worker.py --dataset 1 --model weighted --horizon 5
$ python printer.py
