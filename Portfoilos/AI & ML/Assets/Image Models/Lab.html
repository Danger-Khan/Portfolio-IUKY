Engine: Image Editor

Filters and convolution kernels, written by hand.

No canvas filter shorthand here — every effect below is a real pixel-array algorithm in Image Editor/editor-engine.js: grayscale, invert, sepia and threshold are per-pixel formulas; blur, sharpen and emboss are 3x3 convolution kernels; edge detection is a genuine Sobel operator. Image Editor/editor_cli.py runs the identical filters on real .ppm files from a terminal — same maths, checked twice.

Engine: Image Generation

A small neural network, trained live, right here.

A real, if deliberately tiny, neural network: a plain feedforward MLP that learns the function (x, y) → (r, g, b) for one target image, trained by hand-written backpropagation in Image Genertaion/generator-engine.js — no TensorFlow.js, no ONNX, no pretrained weights. Because it learns a continuous function instead of storing pixels, it can render at a higher resolution than it trained on, or be sampled with the input coordinates jittered by Gaussian noise for a distorted "variation". generator_cli.py trains the identical network in pure Python. Honestly: this warps and upsamples one learned image, it does not generate new scenes from a prompt the way a diffusion model does.
