// small compiler, real algorithm

Translate a real subset of Python into JavaScript, C, Java, or Go.

A hand-written lexer, a recursive-descent parser building a real AST, a multi-pass type-inference step, and four independent backend code generators -- no LLM call, no shelling out to an existing compiler, no network request. This is a genuine, clearly bounded SUBSET of Python (see "What's supported" below), translated correctly rather than a large, fuzzy language pretending to be fully covered. Engine.js runs it here in the browser; compiler_cli.py is the same algorithm again in Python, runnable from a terminal.

what's supported

A real, honestly bounded subset -- not a fuzzy "mostly Python."

Everything listed as supported is genuinely, correctly translated. Everything else raises a clear, line-numbered compile error instead of guessing or producing quietly wrong output.

Supported

  • int / float / string / bool / None literals
  • Arithmetic: + - * / // % ** (Python-correct % and //)
  • Comparisons and and / or / not
  • if / elif / else, while, for x in range(...)
  • Top-level function defs, return, recursion
  • print(...), pass / break / continue, comments
  • A small "magic_lines" cache for a few common snippets

Not supported (by design)

  • Lists, dicts, tuples, sets
  • Classes, exceptions, generators, closures
  • String methods, f-strings, .format()
  • Multiple assignment / unpacking, comprehensions
  • imports, default/keyword arguments
  • Assigning None to a variable (no nullable type here)
  • Reassigning a variable to a different type
