3. Important CNC Concepts

Modal vs. Non-Modal Codes

Modal Codes: Remain active until cancelled or replaced by another code from the same group.
Examples: G90 (Absolute), G17 (XY Plane), G54 (Work Offset).

Non-Modal Codes: Execute only on the line (block) they are programmed on.
Examples: G04 (Dwell), G28 (Return to Home), G53 (Machine Coordinates).

Tool Offsets

H = Tool Length Offset: Associates a length value with the tool.
Example: G43 H01

D = Cutter Radius Comp: Associates a diameter/radius value for profiling.
Example: G41 D01

4. Sample CNC Program (Milling)

This is a standard initialization and basic contouring program.

% O1001 (Part 1 - Contour) G21 G17 G90 G40 G49 G80 (Safety block: Metric, XY, Absolute, Cancel Comps/Cycles) G54 (Select Work Offset 1) T1 M06 (Call Tool 1, Execute Tool Change) S1500 M03 (Spindle Speed 1500 RPM, Forward) G00 X0 Y0 (Rapid move to X0 Y0) G43 H01 Z50.0 (Apply Tool Length Comp 1, Rapid to Z50 clearance) G01 Z-5.0 F200 (Feed into part to Z-5 at 200 mm/min) G01 X50.0 (Cut to X50) Y50.0 (Cut to Y50) X0.0 (Cut to X0) Y0.0 (Cut to Y0) G00 Z100.0 (Rapid retract to Z100) M05 (Spindle Stop) M30 (End of Program / Rewind) %

6. Speeds and Feeds Formulas

Spindle Speed (RPM)

RPM = (1000 × Vc) / (π × D)

Where Vc = Cutting Speed (m/min) and D = Tool Diameter (mm). Use 3.82 instead of 1000 for Imperial (SFM/Inches).

Feed Rate (mm/min or in/min)

Feed = RPM × Z × fz

Where Z = Number of Flutes (Teeth) and fz = Feed per tooth (chip load).

7. Safety Checklist

  • Always home the machine before machining.
  • Verify tool offsets (length and wear) are set correctly.
  • Simulate the program on the control screen before running.
  • Check work offsets (G54–G59) are accurately probed.
  • Ensure coolant settings are aimed correctly at the cutting zone.
  • Confirm spindle direction (M03 for right-hand tools).
  • Keep a hand on the Feed Hold button during first article prove-out.
