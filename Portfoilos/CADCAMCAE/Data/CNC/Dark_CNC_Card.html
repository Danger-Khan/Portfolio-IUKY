Controller Ecosystem

Fanuc (Industry Standard)

Architecture: Highly reliable, standardized ISO G-code. Dominates the Asian and American markets.
Key Features: Uses Custom Macro B (G65) for parametric programming. Strict formatting. Requires exact syntax (#100=1).
Common On: Doosan, Matsuura, Makino, Mori Seiki.

Siemens (Sinumerik)

Architecture: Highly advanced, PC-based. Dominates the European market.
Key Features: ShopMill & ShopTurn conversational programming is built-in. High-level language native support (e.g., IF/THEN/ELSE without strict macro calls). Variables are named (e.g., R1=10).
Common On: DMG Mori, Grob, Hermle.

Mitsubishi (Meldas / M800)

Architecture: Extremely fast processing, G-code syntax is highly compatible with Fanuc.
Key Features: Known for advanced high-speed look-ahead for complex 3D mold surfacing. Excellent Navi graphical interfaces.
Common On: Mazak (customized as Mazatrol), Citizen (Swiss).

Heidenhain (TNC)

Architecture: Dialog-based conversational programming (Klartext).
Key Features: Does not rely on standard G-code (though it can run ISO). Uses distinct buttons for lines (L), circles (C), and chamfers (CHF). Superior for 5-axis mold making.
Common On: Hermle, Mikron, Kern.

Haas (Next Generation Control)

Architecture: User-friendly, proprietary but heavily Fanuc-based.
Key Features: Visual Programming System (VPS), highly intuitive tool setup screens, specific M-codes (M130 for media display). Incredible documentation.
Common On: Haas Automation exclusively.
