03Manufacturing & CAM

Modelling is half the job — these files reflect the path from part to production.

From model to build plate

Every part in the Desktop Filament Recycler and its planetary gear train was sliced into its own G-code build file — batched across print beds by material (PLA / PETG / TPU / FLEX) and print time, so each run stays predictable on the shop floor. Separate reference material was compiled for CNC machining practice: quick-reference cards and a full CNC handbook, alongside injection-mold work carried over from professional experience at SK Engineering.

  • CAM toolpaths generated (G-code) 65
  • Print materials used PLA / PETG / TPU / FLEX
  • Mold design revisions (PCSIR) 2
  • CNC reference documents compiled 6+
