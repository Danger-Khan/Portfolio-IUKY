Slicer Lab

A real G-code analyzer, a material settings advisor, and a filament cost calculator. Pick any .gcode file (including the five real ones sitting in this portfolio's own ../Freelance folder) and this page reads the slicer's own summary comments straight out of it — print time, filament used, cost, material, temperatures — entirely in your browser via the File API. Nothing is uploaded anywhere.

4 · Filament Cost Calculator

Weight and a price per kg gives you the cost — same arithmetic a slicer does internally.

Prefer the terminal? python analyzer.py "../Freelance/33m,PETG,cabletiebelttensioner.gcode" from this folder parses the same real file and prints an identical report — useful for batch-checking a folder full of G-code before a print run. Run python analyzer.py --materials to print the Material Settings Advisor table, or python analyzer.py --cost 56.5 4500 for the cost calculator.
What this actually is: the G-code Analyzer only reads comment lines PrusaSlicer itself writes into the file — it doesn't slice, simulate, or estimate anything on its own, so a file from a different slicer (Cura, OrcaSlicer, Bambu Studio) may show fewer fields if its comment format differs. The Material Settings Advisor and Filament Cost Calculator are fixed reference data and arithmetic, not a trained model.
