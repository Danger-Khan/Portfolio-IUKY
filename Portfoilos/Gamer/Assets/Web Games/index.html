Web Games
Gamer Portfolio How it works
Playable · Offline · No dependencies

Six small games, one engine, zero downloads.

Every game here runs on the same engine.js — a fixed-timestep loop, input handling, a hi-dpi canvas, and the start/pause/game-over shell. There is no game framework, no sprite sheet and no audio file anywhere in this folder: the artwork is drawn with canvas paths at runtime and the sound is synthesised with WebAudio oscillators. Open any of these from a USB stick on a machine with no internet and they still work.

Pick a game

Each one has a full instruction manual on its own page. Keyboard and touch both work. Best scores are kept in this browser only.

What's in this folder

The arcade is six games plus the shared plumbing they all sit on.

engine.js

The shared runtime. Fixed 120 Hz physics stepping with an accumulator, so a game runs identically on a 60 Hz and a 144 Hz screen instead of speeding up. Also input, procedural audio, particles, collision helpers and the overlay shell.

javascript.js

The hub: the game catalogue, the cover art (each one a canvas drawing function, not an image file), best-score lookup, and the shared page chrome.

styling.css

One stylesheet for the hub and all six game pages, matching the Gamer portfolio's palette.

database_use.sql

The score-table schema. Scores live in localStorage by default; this is the shape they take if you ever run the optional backend.

backupengine.php

An optional score-sync endpoint for anyone self-hosting this on a PHP server. It is off unless you switch it on below, and the games work exactly the same when it is missing — which it is on static hosting.

One folder per game

Each holds its index.html (the shell and the manual) and its game.js (just that game's rules). Nothing else is needed.

On assets: nothing here needs downloading. Every visual is generated in code and every sound is synthesised, so there are no missing textures to hunt down and no licences to chase. That was a deliberate constraint, not a shortcut — it is what makes the folder genuinely portable.
